# Campus Events Guide

## About the Project
Campus Events Guide is a website that helps students find campus events and check their details, schedules, and registration information.

## Project Pages
- **index.html:** The home page with featured events.
- **events.html:** Shows upcoming and past campus events.
- **event-details.html:** Shows the details and agenda of Tech & Innovation Day, with a video and review form.
- **schedule.html:** Shows the events timetable.
- **registration.html:** Contains the event registration form.
- **style.css:** Contains the design and styles for all pages.
- **assets:** Contains the event images.

## Technologies Used
- HTML5
- CSS3

## Features
- Navigation between all five pages.
- Event cards with images and information.
- An event timetable.
- Registration and review forms.
- HTML5 form validation.
- Responsive design for mobile and desktop screens.
- Dark mode using CSS only.

## How to Run
1. Download or extract the project folder.
2. Make sure all HTML files, `style.css`, and the `assets` folder are together.
3. Open `index.html` in Google Chrome or Microsoft Edge.
4. Use the navigation menu to open the other pages.

## Notes
- The forms are for demonstration and do not save or send information.
- The sample video needs an internet connection.
- Event information is used for demonstration purposes.
